03

Technical Details & Next Steps

🔗

Supply Chain Pipeline

Every PR triggers 4 parallel CI jobs: cargo-deny license check, advisory audit, CycloneDX SBOM generation, and gitleaks secret scanning.

🔐

Keyless Signing

Sigstore Fulcio + Rekor for OIDC-based keyless signing. No long-lived keys — identity bound to GitHub Actions OIDC token.

🛡️

Security Headers

Custom axum middleware adds 6 security headers: CSP, X-Frame-Options: DENY, nosniff, XSS-Protection, Referrer-Policy, Permissions-Policy.

🧪

Test Architecture

36 unit tests covering: C-string decoding, sliding window, alert thresholds, auto-kill, process tree, Shannon entropy, extension extraction.
